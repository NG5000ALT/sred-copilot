### Bugs found and fixed in those runs
1. Sonnet 5.5 rejects forced `tool_choice`. Switched to structured outputs (`output_config.format`); the lookup loop uses `auto` with a reminder.
2. SurrealDB escapes some record ids (`project:⟨0d4s…⟩`), and the model echoed them back unescaped, silently dropping 30 of 65 evidence items. The model now sees Jira epic keys instead.
3. The tagger dropped routine work, so the dashboard project had no evidence to rule out. Tag prompt v2 keeps routine work, tagged "routine".
4. The number checker treated names as claims (`Cortex-A72`, `FP32`, `BRT-7`, `SOP-021`, "run 1"). It now ignores them and accepts numbers from the cited record's title.
